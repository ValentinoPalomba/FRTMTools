# Audit report design

The report prioritizes measured facts and readable evidence for technical reviewers and management. It remains a standalone offline HTML document.

- System sans serif typography; monospace for identifiers, versions and paths.
- White surfaces, cool gray background, slate text and restrained blue accents; corresponding dark palette.
- Maximum content width 1480 px; responsive padding 40/24/16 px.
- Flat metric strips with explicit units; no decorative gradients.
- Horizontal bars and doughnuts retain exact underlying values and visible legends. Color always accompanies labels.
- Findings expose priority, identity and CWE before expandable evidence and correction.
- Inventories support search, numeric sorting and 25/50/100-row pagination.
- Candidate advisories show included/upstream versions, identifiers, ranges and correction; all fields remain expandable.
- Keyboard tab navigation, visible focus, reduced motion and print expansion of all rows.
- No localization inventories, methodology sections or source lists. Direct advisory links remain available.
